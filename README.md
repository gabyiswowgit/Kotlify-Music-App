# Kotlify-Music-App

Kotlify is a music managment app where you can create playlists, add, delete, edit, and/or sort songs in the playlists, view song details such as title, artist, album, genre, duration, release year and how many playlists a song has been added to.
You can also view all the playlists you made, view playlist details, edit and/or delete playlists, add, remove, and filter songs in playlists. 
There will be a menu for playlists and a menu for songs, and a submenu for filtering songs
